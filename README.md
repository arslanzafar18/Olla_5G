# 5G NR Link Adaptation with OLLA under Imperfect CQI Feedback

Course project for **DAT-610 Wireless Communication**, University of Stavanger.

This repository contains a MATLAB study of downlink link adaptation in 5G NR. It looks at how **Outer Loop Link Adaptation (OLLA)** keeps the block error rate (BLER) near a 10% target when the UE's Channel Quality Indicator (CQI) reports are noisy, delayed or biased, and how this changes with UE mobility.

## Overview

The base station picks a modulation and coding scheme (MCS) from the CQI the UE reports. In practice that CQI is imperfect: it is noisy, it arrives late, and it can be systematically biased. OLLA corrects for this by shifting the SINR used for MCS selection a little after every ACK or NACK, so the long-run BLER converges to the target.

The project measures how much OLLA helps, and how robust it is, across:

- OLLA **on vs. off**
- SNR operating point
- OLLA **step size**
- CQI error (**noise sigma** x **feedback delay**)
- CQI **bias**
- UE **mobility** (3, 30 and 120 km/h)

Metrics: throughput, BLER, average MCS and convergence time of the OLLA offset.

## Method

The study uses two levels of simulation:

1. **Link level (real 5G PHY).** A full PHY chain built from MATLAB 5G Toolbox (`nrDLSCH`, `nrPDSCH`, `nrTDLChannel`) over a TDL-C channel (300 ns delay spread, 30 kHz SCS, 51 PRB) with perfect channel estimation, MMSE equalisation and LDPC decoding. It produces **BLER-vs-SINR curves for every CQI/MCS** (3GPP CQI table 1).
2. **Link adaptation level (fast simulator).** Long closed-loop runs use the calibrated BLER curves together with a TDL-C channel trace and a capacity-effective SINR (link-to-system abstraction). This makes many seeds and long runs practical.

`main_3_phy_validation.m` validates the fast simulator against full-PHY closed-loop runs.

## Getting started

Put **all files in one folder**, set it as the MATLAB current folder, then run the scripts **in this order**:

| Step | Script | Runtime | What it does | Output |
|------|--------|---------|--------------|--------|
| 1 | `main_1a_calibrate.m` | ~10-20 min (once) | Real 5G PHY over TDL-C, BLER-vs-SINR curves per CQI/MCS | `calibration.mat`, `results/fig0_calibration.png` |
| 2 | `main_1b_traces.m` | ~5-15 min (once) | TDL-C channel traces for 3, 30 and 120 km/h | `trace_3kmh.mat`, `trace_30kmh.mat`, `trace_120kmh.mat` |
| 3 | `main_2_experiments.m` | a few min | All report figures and tables (OLLA on/off, SNR, step size, CQI sigma x delay, CQI bias, mobility) | `results/` |
| 4 | `main_3_phy_validation.m` | ~5-15 min | Full-PHY closed loop vs. the fast simulator | validation figures |

Steps 1 and 2 only need to be run once. Their output files are reused by steps 3 and 4.

## Simulation setup

| Parameter | Value |
|-----------|-------|
| Channel | TDL-C, 300 ns delay spread |
| Subcarrier spacing | 30 kHz |
| Bandwidth | 51 PRB |
| Channel estimation | Perfect |
| Equaliser | MMSE |
| Channel coding | LDPC (`nrDLSCH`) |
| CQI table | 3GPP CQI table 1 |
| BLER target | 10% |
| UE speeds | 3, 30, 120 km/h |

## Troubleshooting

If a 5G Toolbox call errors on the first run, the MATLAB error message names the exact function and line. Check that all three toolboxes are installed (`ver`) and that all files are in the current folder.
